# Glossário de tradução

Termos do Rastro nos três idiomas ([ADR-009](../adr/adr-009-multilingue.md)). Toda tradução de tela, mensagem e documentação parte daqui. Termo novo do produto entra aqui antes de entrar nos arquivos de tradução.

## Regras de estilo

| | Inglês (`en-US`) | Espanhol (`es`) |
|---|---|---|
| Tratamento | "you", direto | "tú", neutro latino-americano (sem "vosotros", sem voseo) |
| Botão | verbo no imperativo, só a primeira letra maiúscula ("Run validation") | verbo no infinitivo ("Ejecutar validación") |
| Título de tela | só a primeira letra maiúscula ("Flow map") | só a primeira letra maiúscula ("Mapa del flujo") |
| Número e data | pelo idioma ativo, nunca formato fixo | pelo idioma ativo, nunca formato fixo |
| Reticências | "Browse…" (caractere único) | "Examinar…" (caractere único) |

Nunca se traduz: Rastro AI, nomes de produto (.NET, Angular, Roslyn, MCP, Claude, OpenAI, Gemini, SQL Server, PostgreSQL, Structurizr, Mermaid), identificadores, `extracted`, `inferred`, `confirmed` quando aparecem como valor técnico.
